自设红线 · 一处违反

设计期的 oracle 咨询

为判断某机制是否值得建,我把一个候选答案跑过一次官方 validator(单次,不调格式)。

按判据不构成泄露(它查 agent 轨迹,且限定「驱动了通过答案」,而该题仍 0/3),但违反我们写在 roadmap 里的红线,应在任何提交说明中如实列出。

DEPS q1 — +0.042。离线已证我们的栈能算出通过答案;失分在读法。竞对 1–2/5,对所有人都是掷硬币。

不做的两题

PANCANCER q1 — 方括号限定词在两个候选列上都是空操作,题面措辞对两列对称,数据侧无可判定信号。

GITHUB q1 — 队列侧已上机制,分子侧符号 union 上限实测 0.1913,而需要 0.33;两侧都够不着。

继续推进都只能猜评分口径,按北极星不做。
